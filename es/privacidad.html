Privacidad

Alpha Galaxy Coatings usa actualmente un sitio web estático. La calculadora de estimado preliminar funciona localmente en tu navegador y no transmite ni almacena lo que ingresas.

Esta versión no usa rastreadores de publicidad, cookies de analítica, inicio de sesión ni un panel público de administración.

Cuando se active el flujo seguro de ServiceSales AI, esta política se actualizará antes de recopilar información personal. Solo se solicitarán los datos necesarios para responder a una solicitud de servicio.

Seguridad

Las contraseñas, API keys y credenciales privadas nunca deben estar en el código público del sitio. El hosting de producción debe aplicar HTTPS y las cabeceras de seguridad incluidas en este paquete.
